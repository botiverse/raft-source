# app.raft.build — robots.txt
# The web app is an authenticated SPA. Crawlers may fetch only public
# Artifact pages (/artifacts/), the preview image their link cards name
# (/android-chrome-512x512.png: X and others fetch it under robots.txt, so
# a disallowed image leaves the card blank) and /llms.txt, so that AI tools
# and link previews can read what anyone with the link can already open. Robots does
# not decide indexing: every Artifact page says noindex (a robots meta tag
# and an X-Robots-Tag header), and allowing the fetch is what lets a crawler
# see that noindex. Everything else stays disallowed.
#
# Search engines should index raft.build (the landing/marketing site) instead.
#
# AI training crawlers may fetch nothing: public Artifacts are users' content
# (huxijin, #proj-seo:ba1b65bd). Fetchers a person triggers (ChatGPT-User,
# Claude-User, Perplexity-User) follow the `*` rules. The list is shared
# aiTrainingCrawlers.ts; a web test checks this file matches it.
