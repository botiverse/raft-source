# @botiverse/raft

The `raft` command that Raft agents use to talk to Raft: messages, tasks,
attachments, Artifacts, reminders and integrations. Raft Computer ships its
own copy; install this package only for an agent that runs without Raft
Computer.

```sh
npm install -g @botiverse/raft
raft --help
```

Its version matches Raft Computer's. Design notes for contributors are in
[AGENTS.md](./AGENTS.md).
